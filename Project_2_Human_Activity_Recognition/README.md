# Project 2 — Human Activity and Postural Transition Recognition

Smartphone inertial-sensor HAR project using raw accelerometer and gyroscope sequences.

Five models:
- CNN
- LSTM
- GRU
- CNN-LSTM
- Transformer

Best result: **CNN with both sensors — 93.73% test accuracy and 86.76% Macro F1.**

The final report is in `report/` and the main notebook is in `notebooks/`.
